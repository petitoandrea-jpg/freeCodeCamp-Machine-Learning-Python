# Machine Learning with Python - freeCodeCamp Projects

This repository contains the 5 practical certification projects developed for the **freeCodeCamp Machine Learning with Python** curriculum, covering Deep Learning, Natural Language Processing, Computer Vision, and Predictive Modeling.

---

## 🚀 Projects Overview

### 1. Cat and Dog Image Classifier (`cat_dog_classifier/`)
* **Focus**: Computer Vision & Deep Learning
* **Tech Stack**: TensorFlow, Keras, Matplotlib
* **Summary**: Implemented and trained a Convolutional Neural Network (CNN) to classify images into binary classes (cats vs. dogs). Utilized ImageDataGenerator for data preprocessing and data augmentation (random flips, rotations, zooming) alongside Dropout layers to reduce overfitting.

### 2. Neural Network SMS Text Classifier (`sms_classifier/`)
* **Focus**: Natural Language Processing (NLP) & Sequence Modeling
* **Tech Stack**: TensorFlow, Keras, Tokenizer, Padding
* **Summary**: Built a recurrent neural network (RNN / LSTM) pipeline for text classification. Processed raw SMS data via text tokenization, vectorization, and sequence padding to predict whether a message is spam or legitimate (ham).

### 3. Book Recommendation Engine using KNN (`book_recommendation/`)
* **Focus**: Unsupervised Learning & Recommender Systems
* **Tech Stack**: Scikit-Learn, Pandas, NearestNeighbors
* **Summary**: Built a collaborative filtering recommendation model using the k-Nearest Neighbors (KNN) algorithm with cosine metric to identify and suggest books with similar rating patterns across users.

### 4. Linear Regression Health Costs Calculator (`linear_regression/`)
* **Focus**: Supervised Learning & Regression
* **Tech Stack**: TensorFlow / Keras, Pandas, Matplotlib
* **Summary**: Constructed a regression neural network to predict individual healthcare costs based on demographic and lifestyle indicators (age, BMI, smoking habits). Tuned layer dimensions and loss functions (MAE/MSE) to maximize prediction accuracy.

### 5. Rock Paper Scissors AI (`rock_paper_scissors/`)
* **Focus**: Pattern Recognition & Adaptive Game Theory
* **Tech Stack**: Python
* **Summary**: Designed an adaptive strategy agent capable of tracking and anticipating multi-step opponent move histories (Markov chain / n-gram frequency analysis) to maintain a >60% win rate against multiple heuristic bots.
